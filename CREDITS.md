## 3D Models, Materials & Audio
- All 3D geometry (Mây with conical hat *nón lá* and hanging lantern, Grand Lanterns, Fireflies, Ink Shades, Đảo Bến island, cloud sea) is procedurally generated in code (`web/game.js`).
- All sound effects (firefly chime, lantern deposit/lighting chord, light pulse whoosh, shade hit thud) are procedurally synthesized via the browser Web Audio API (`web/game.js`).
